# MV TEACHES - Demo & Master Prompt

هذا المستودع يحتوي على التصميم المبدئي (Demo) التفاعلي الخاص بمنصة **MV TEACHES** لتعليم اللغة الإنجليزية، بالإضافة إلى **البرومبت الشامل (Master Prompt)** الذي يوثق كافة متطلبات المشروع المعمارية والبرمجية.

## الديمو التفاعلي (Interactive Demo)
تم بناء الديمو باستخدام HTML, CSS, JavaScript ليعمل كصفحة واحدة (SPA) تحاكي:
- **الموقع العام (Public Website):** مع ميزة تغيير الأسعار والعملات ديناميكياً بين فرعي الأردن وفلسطين.
- **بوابة الطالب (Student Portal):** واجهة لوحة تحكم الطالب، جدول الحصص، نموذج طلب الاعتذار، والملخص المالي.

---

## البرومبت الشامل (Master Prompt)
هذا البرومبت هو الدليل الشامل لبناء النظام البرمجي بالكامل:

**الهدف (Objective):**
أنت تعمل كمطور ومهندس برمجيات (Full-Stack Developer & Software Architect). يطلب منك بناء وتطوير منصة تعليمية إلكترونية متكاملة 100% (بدون أي حصص حضورية) لتعليم اللغة الإنجليزية عبر "Zoom" لصالح أكاديمية **MV TEACHES**. المنصة تخدم فرعين مستقلين (الأردن وفلسطين) وتدار من لوحة تحكم مركزية واحدة.

### 1. الهوية البصرية والتصميم (Branding & UI/UX)
- **الاسم:** MV TEACHES - British English. Global Opportunities.
- **الألوان الأساسية:** الكحلي الداكن (Dark Blue)، العنابي/الأحمر الداكن (Burgundy)، والذهبي (Gold).
- **الطابع العام (Vibe):** تصميم احترافي، بريطاني أصيل، عصري (Premium & Glassmorphism)، وموثوق.
- **الجمهور المستهدف:** الأطفال (7-17 سنة)، البالغين (18+).

### 2. بنية النظام والفروع (System Architecture)
يعتمد النظام على هيكلية تدعم فرعين منفصلين تحت سقف واحد:
- **فرع الأردن:** العملة (دينار أردني JOD).
- **فرع فلسطين:** العملة (تُحدد لاحقاً: شيكل / دولار).
- **الاستقلالية:**
  - التسعير والباقات: مستقلة بالكامل لكل فرع.
  - الحصص والجدولة: مستقلة بالكامل لكل فرع.
  - بوابات الدفع: مفتوحة حالياً (تحويل بنكي/محافظ)، ولاحقاً بوابات دفع إلكترونية منفصلة لكل فرع.
- **المركزية:** لوحة إدارة (Admin Dashboard) موحدة تشرف وتدير الفرعين معاً من نفس الحساب.

### 3. نطاق العمل الأساسي (Scope of Work)
المنصة تتكون من 4 واجهات رئيسية، بالإضافة إلى تكاملات برمجية خارجية:
1. الموقع العام (تسويقي وتسجيل).
2. بوابة الطالب (Student Portal).
3. بوابة المعلم (Teacher Portal).
4. لوحة الإدارة الموحدة (Admin Dashboard).
5. **التكاملات (Integrations):** Zoom (لإنشاء وإدارة الحصص)، بوابات الدفع، نظام تنبيهات (Email + WhatsApp).

### 4. تفاصيل الشاشات والوظائف (Detailed Screens & Features)

**أولاً: شاشات الموقع العام (Public Website)**
- **الصفحة الرئيسية:** وصف الأكاديمية وقيمتها، **اختيار الفرع (الأردن/فلسطين)** لتوجيه الزائر، روابط الصفحات، ودعوة للتسجيل كطالب أو التقدم كمعلم.
- **صفحة البرامج/الدورات:** عرض المسارات (A1 إلى C2)، ووصفها، مع زر يربط لصفحة الأسعار الخاصة بالفرع المختار.
- **صفحة الأسعار والباقات:** **شاشة ديناميكية** تقرأ الفرع المختار تلقائياً وتعرض العملة والباقات.
- **نموذج التقديم كمعلم:** لاستقبال الطلبات (الاسم، الجنسية، مؤهل CELTA/TESOL، الخبرة، السيرة الذاتية).
- **تسجيل الدخول / إنشاء حساب:** عند التسجيل، يُجبر الطالب على اختيار فرعه ويكون الاختيار ثابتاً.

**ثانياً: شاشات بوابة الطالب (Student Portal)**
- **الرئيسية (لوحة التحكم):** نظرة عامة سريعة.
- **حصصي:** عرض جدول الحصص (بتوقيت الطالب المحلي)، إظهار **رابط Zoom تلقائياً** قبل موعد الحصة.
- **سجل الحضور:** متابعة ذاتية لحالة كل حصة (حضر / غاب / تم التأجيل).
- **طلب اعتذار عن حصة:** تقديم عذر ضمن مهلة زمنية محددة.
- **حسابي المالي:** متابعة الباقة وتاريخ انتهائها، سجل الفواتير.
- **امتحان تحديد المستوى:** اختبار إلكتروني تحدد نتيجته المستوى.
- **تقدمي التعليمي / الشهادات:** إمكانية تحميل شهادات الإتمام بصيغة (PDF).

**ثالثاً: المحاسبة المزدوجة (Dual Accounting System)**
- **حساب الطالب:** تتبع الاشتراكات، الفواتير، والمستحقات.
- **حساب المعلم:** تتبع أجور المعلمين، الحصص المنجزة.

### 5. المتطلبات التقنية والملاحظات الختامية
- دعم كامل للغة العربية (RTL).
- التنبيهات (Reminders & Cancellations) تتم بشكل آلي عبر البريد الإلكتروني والواتساب.
- الفصل التام في قواعد البيانات أو هيكلة البيانات بين مبيعات/حصص الأردن وفلسطين.
